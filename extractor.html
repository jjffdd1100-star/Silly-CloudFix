      💡 헤더 복사하는 초간단 방법:
      
    
        
  1. PC 브라우저(크롬/엣지)에서 [janitorai.com]에 로그인합니다.
    2. 
        
  2. 키보드의 F12 키를 눌러 개발자 도구를 열고 상단의 Network 탭을 클릭합니다.
    3. 
        
  3. 화면에서 아무 캐릭터나 클릭하거나 F5로 새로고침합니다.
    4. 
        
  4. 네트워크 목록에서 3f8a1c4d-e729-40b2-9156-... 처럼 알파벳·숫자·대시(-) 조합으로 생긴 UUID 형태의 요청을 클릭합니다.
    5. 
        
  5. 우측 창의 Headers -> Request Headers 목록에서 Cookie: 뒷부분(또는 Request Headers 전체)을 복사하여 위 입력창에 넣고 [토큰 추출하기]를 누르면 끝!
