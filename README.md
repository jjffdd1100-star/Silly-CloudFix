# Silly-CloudFix ☁️

> **실리태번(SillyTavern) 코어를 건드리지 않고 JanitorAI · JannyAI 공개 캐릭터와 로어북을 바로 가져오는 단일 서버 플러그인**

실리태번 기본 **구름 불러오기(Cloud Import)** 가 막혀 있을 때, 별도 코어 수정이나 확장 프로그램 중복 설치 없이 `plugins/` 폴더 하나만으로 캐릭터 카드·아바타·연결된 로어북 전체를 깔끔하게 가져옵니다.

### 한눈에 보는 장점
- **코어 수정 제로**: 실리태번 업데이트(`git pull`) 시 코드 충돌이 나지 않습니다.
- **즉시 드롭다운 반영 (`F5` 불필요)**: 캐릭터 임포트 직후 `Silly-CloudFix Auto Sync`가 월드 인포 드롭다운과 기본 로어북 연결 상태를 자동으로 갱신합니다. (채팅창이나 브라우저 전체를 새로고침하지 않습니다.)
- **아바타 무결성 검증 & 로어북 보호**: 손상 이미지·잘린 JPEG/WebP·APNG·HTML 오류 응답이 기본 아바타(`ai4.png`)로 몰래 대체되는 현상을 막고, 기존 로어북과 다른/수정된 로어북은 `(2)`, `(3)` 번호로 분리해 덮어쓰기를 방지합니다.
- **내장 웹 설정 UI**: 실리태번 실행 중 `/api/plugins/silly-cloudfix/` 에서 상태 확인, 쿠키 파싱, 원클릭 `token.json` 저장까지 한 번에 끝낼 수 있습니다.

## 🚀 최초 설치 및 설정 (4단계)

### 1단계. `config.yaml`에서 서버 플러그인 켜기
실리태번 루트 폴더의 `config.yaml` 파일을 열어 아래 옵션을 `true`로 변경합니다.

```yaml
# config.yaml
enableServerPlugins: true   # 기본값 false -> true 로 변경
```

> [!IMPORTANT]
> `enableServerPlugins: true` 가 켜져 있지 않으면 실리태번이 `plugins/` 폴더를 아예 읽지 않습니다.

---

### 2단계. `plugins/` 폴더에 설치하기
실리태번 웹 UI의 **확장 다운로드(Download Extension)** 메뉴는 클라이언트 확장(`extensions/`) 전용입니다. **Silly-CloudFix는 반드시 `plugins/` 폴더에 설치**해야 합니다.

| 설치 방식 | 방법 |
| :--- | :--- |
| **Git Clone (추천)** | `SillyTavern/plugins` 폴더에서 터미널을 열고 실행:<br>`git clone https://github.com/jjffdd1100-star/Silly-CloudFix.git` |
| **ZIP 수동 설치** | 저장소 상단 `Code` → `Download ZIP` 후 압축 해제 → 폴더명을 `Silly-CloudFix`로 맞춰 `SillyTavern/plugins/` 안에 복사 |

---

### 3단계. 실리태번 서버 재시작 (필수)
서버 플러그인은 브라우저 새로고침(`F5`)이 아니라 **실리태번 서버(`Start.bat` 등)가 부팅될 때** 로드됩니다.
1. 실행 중인 실리태번 콘솔 창을 완전히 닫습니다.
2. 서버를 다시 실행하고 콘솔에 `[Silly-CloudFix] Initializing plugin...` 로그가 뜨는지 확인합니다.

---

### 4단계. JanitorAI 토큰 추출 및 저장

#### ① 브라우저에서 Cookie 복사하기
1. PC 브라우저에서 [janitorai.com](https://janitorai.com)에 로그인합니다.
2. **`F12`** 키를 눌러 개발자 도구를 열고 상단 **`Network` (네트워크)** 탭을 선택합니다.
3. 화면에서 아무 캐릭터나 클릭하거나 **`F5`** 로 새로고침합니다.
4. 요청 목록에서 **`3f8a1c4d-e729-40b2-9156-...`** 처럼 **알파벳·숫자·대시(`-`) 조합의 UUID 형태 항목**을 클릭합니다.
5. 오른쪽 **`Headers` → `Request Headers`**에서 **`Cookie:`** 줄의 값(또는 Request Headers 전체)을 복사(`Ctrl + C`)합니다.

#### ② 토큰 저장하기 (둘 중 편한 방법 선택)
- **방법 A · 실리태번 내장 웹 페이지에서 원클릭 저장 (추천)**
  1. 실리태번이 켜진 상태에서 브라우저로 아래 주소에 접속합니다 *(포트가 다르면 본인 포트로 변경)*:
     `http://127.0.0.1:8000/api/plugins/silly-cloudfix/`
  2. 상단에서 플러그인 연결·토큰 상태를 확인하고, 입력창에 복사한 텍스트를 붙여넣습니다.
  3. **[🔑 토큰 추출하기]** → **[💾 실리태번에 바로 저장]** 을 누르면 즉시 `token.json`에 반영됩니다. *(재시작 불필요)*

- **방법 B · `extractor.html` 더블클릭으로 수동 저장**
  1. `SillyTavern/plugins/Silly-CloudFix/extractor.html` 을 더블클릭해 엽니다.
  2. 붙여넣기 → **[🔑 토큰 추출하기]** 후, 내용 복사 또는 `token.json` 다운로드로 `plugins/Silly-CloudFix/token.json` 에 저장합니다.

```json
{
  "janitor_refresh_token": "여기에_추출한_리프레시_토큰",
  "janitor_key": "여기에_추출한_긴_JWT_액세스_토큰"
}
```

> [!TIP]
> - `janitor_refresh_token` 이 함께 저장되어 있으면 액세스 토큰이 만료되더라도 플러그인이 자동으로 새 토큰을 받아 `token.json`을 갱신합니다.
> - 토큰을 추출한 브라우저에서 **직접 [로그아웃(Log out)]을 누르면 리프레시 토큰이 즉시 무효화**됩니다. 추출 후에는 로그아웃하지 말고 탭만 닫아 주세요.
> - `extractor.html` 및 내장 UI의 토큰 파싱은 100% 내 PC 로컬에서만 처리되며 외부로 전송되지 않습니다.

## 🎮 사용 방법

### 1. 캐릭터 및 로어북 가져오기
1. 실리태번 상단 **구름 아이콘 (외부 URL에서 가져오기)** 을 클릭합니다.
2. `https://janitorai.com/characters/...` 또는 `https://jannyai.com/characters/...` 링크를 입력합니다.
   - 여러 줄(엔터 구분)로 붙여넣어 **일괄 다운로드**도 가능합니다.
3. 완료되면 캐릭터 시트, 아바타, 연결된 공개 로어북이 모두 저장됩니다.

### 2. 로어북 자동 반영 및 중복 보호
- **드롭다운 & 기본 로어북 자동 연결**: 임포트가 끝나는 즉시 `worlds/`에 저장된 **대표 로어북 + 추가 공개 로어북 모두** 브라우저 월드 인포 드롭다운과 캐릭터 로어북 목록에 자동 반영됩니다. 브라우저 `F5`나 채팅창 새로고침 없이 바로 선택할 수 있습니다.
- **기존 파일 안전 비교 및 `(2)`, `(3)` 분리**:
  - 이미 같은 이름의 로어북이 있을 때 **내용이 똑같으면 기존 파일을 재사용**합니다.
  - 사용자가 실리태번에서 내용을 **수정했거나 다른 로어북이면 `이름 (2)`, `이름 (3)`** 으로 새 파일을 만들어 기존 수정본을 절대 덮어쓰지 않습니다.

> [!NOTE]
> **[카드 로어북 가져오기] 버튼 안내**:
> 실리태번 메뉴에 있는 `[카드 로어북 가져오기]` 버튼은 캐릭터 PNG 안에 들어 있던 **대표 로어북 1개 스냅샷만** 꺼내 같은 파일명으로 강제 덮어쓰는 실리태번 기본 기능입니다. Silly-CloudFix가 대표·추가 로어북을 이미 모두 저장하고 목록에 반영하므로 따로 누르실 필요가 없습니다.

## 🔄 업데이트 방법 (`git pull` / ZIP)

최초 설치 후 새 버전이 올라오면 설치했던 방식 그대로 업데이트하면 됩니다.

- **Git Clone으로 설치한 경우 (추천)**
  1. `SillyTavern/plugins/Silly-CloudFix` 폴더에서 터미널을 엽니다.
  2. 아래 명령어를 실행한 뒤 **실리태번 서버를 재시작**합니다.
     ```bash
     git pull
     ```
  > [!TIP]
  > - 실리태번 `config.yaml` 의 `enableServerPluginsAutoUpdate`가 `true`(기본값)이면 시작 시 자동 `git pull`을 시도합니다. (`false`로 꺼둔 경우에만 위 명령어로 직접 받아주세요.)
  > - 혹시 충돌 안내가 뜨면 `token.json`만 따로 백업한 뒤 `git pull` 후 다시 넣어주세요.

- **ZIP 파일로 설치한 경우**
  1. 최신 ZIP을 받아 기존 `SillyTavern/plugins/Silly-CloudFix/` 에 덮어씁니다.
  2. **내가 토큰을 저장해 둔 `token.json` 파일이 덮어써지지 않도록 백업 후 유지**하고, 서버를 재시작합니다.

## 📋 지원 범위 (되는 것 vs 안 되는 것)

### ✅ 지원하는 기능
- **공개 캐릭터 시트·메타데이터 정밀 변환**: 캐릭터 설명, 첫 메시지, 중복 제거된 대체 첫 메시지, 시나리오, 제작자의 메모, 제작자 이름·버전 및 URL 보존 *(시나리오·성격 하단 재니터 저작권 자동 문구 및 태그 이모지 자동 정리; 제작자·버전·메모·태그 등 선택 필드가 일부 비어도 시트 저장은 정상 완료)*.
- **아바타 선검증 및 정적 PNG 변환**: WebP·JPEG·PNG·APNG 이미지를 검증해 정상 static PNG로 변환하며(잘린 JPEG·손상 PNG·HTML 오류 응답 거부), 실패 시 기본 아바타로 덮어쓰지 않고 임포트를 중단해 불완전 카드 저장을 방지합니다. 같은 캐릭터 동시 중복 임포트도 순차 큐로 보호합니다.
- **공개 로어북 개별 완결 저장**: 캐릭터에 연결된 대표·추가 공개 로어북을 각각 완결성 검증 후 독립 `.json`으로 `worlds/`에 저장합니다. 대용량 로어북 일부에서 오류가 나거나 빈 껍데기 로어가 있어도 반쪽 파일은 남기지 않고 완결된 로어북만 저장하며 캐릭터 시트 다운로드는 정상 완료됩니다.
- **JannyAI 링크 · 일반 UUID 공존**: Janitor/Janny URL과 `_character` ID를 처리하며, Janitor에 없는 일반 UUID(`404`)는 실리태번 기본 핸들러(Pygmalion 등)로 자동 전달합니다.

### ❌ 지원하지 않는 기능
- **비공개(Private) 캐릭터의 가려진 정의 및 비공개 로어북**: 재니터 API가 비공개 정의 필드를 내려주지 않으므로, 공개된 **첫 메시지·대체 첫 메시지·창작자 노트**까지만 가져옵니다.
- **재니터 원본에서 삭제된 캐릭터**: JannyAI에 페이지만 남아있고 재니터 원본에서 삭제된 캐릭터는 가져올 수 없습니다 (`jannyai.com` 자체의 Cloudflare Turnstile 차단). 이 경우 JannyAI 웹 페이지에서 직접 **`Download Card (.png)`** 로 내려받아 넣어주세요.

## ⚙️ 동작 원리 및 폴더 구조

- **서버 앞단 정밀 인터셉트**: `/api/content/importURL` · `/api/content/importUUID` 요청 중 JanitorAI/JannyAI 대상만 가로채 `curl` + Supabase 인증 갱신 락(Mutex)으로 안전하게 처리합니다.
- **무설치 자동 UI 동기화**: 별도 클라이언트 확장을 `extensions/`에 설치하지 않아도 플러그인이 `/api/extensions/discover` 와 `/scripts/extensions/silly-cloudfix-sync/` 를 통해 경량 동기화 스크립트(`client-sync.js`)를 자동 제공하여 드롭다운과 캐릭터 연결 UI만 깔끔하게 갱신합니다.

```text
SillyTavern/
├── config.yaml
└── plugins/
    └── Silly-CloudFix/
        ├── index.js            # 플러그인 본체 (API 인터셉터 · 토큰 자동 갱신 · 로어북 비교/저장 · 웹 UI 서버)
        ├── client-sync.js      # 무설치 자동 동기화 모듈 (임포트 직후 월드 드롭다운 · 연결 아이콘 갱신)
        ├── extractor.html      # 토큰 추출 도구 (로컬 더블클릭 & 내장 웹 설정/진단 UI 겸용)
        ├── package.json
        ├── token.example.json  # 토큰 설정 템플릿
        ├── token.json          # 내 토큰 저장 파일 (최초 실행 시 자동 생성 · git 추적 제외)
        └── README.md
```

## ❓ 자주 묻는 질문 (FAQ)

**Q. 플러그인이 전혀 동작하지 않아요.**
- `config.yaml` 의 `enableServerPlugins: true` 설정 여부와 설치 경로가 **`SillyTavern/plugins/Silly-CloudFix/`** 맞는지 확인해 주세요. (`data/default-user/extensions/` 가 아닙니다.)
- 설치/업데이트 후에는 반드시 실리태번 **서버를 재시작**해야 합니다.

**Q. 내장 상태 확인 페이지는 어디에 있나요?**
- 서버 실행 중 `http://127.0.0.1:8000/api/plugins/silly-cloudfix/` 에 접속하시면 인터셉터 상태, 토큰 만료 여부, 최근 오류, 강제 토큰 갱신 테스트, 쿠키 저장까지 모두 가능합니다.

**Q. 로어북이 여러 개인데 왜 캐릭터 카드에는 1개만 기본 연결되나요?**
- 실리태번 캐릭터 카드 규격 자체가 **기본 로어북 1개(`extensions.world`)** 만 카드에 직접 연결하도록 되어 있습니다.
- 나머지 추가 로어북(`B`, `C`, `D` 등)도 모두 `worlds/`에 함께 저장되고 드롭다운에 즉시 나타나므로, 로어북 서랍(글로벌)이나 캐릭터 **추가 로어북** 드롭다운에서 원하시는 대로 바로 선택해 쓰실 수 있습니다.

**Q. 아바타 오류로 임포트가 실패하거나, 여러 로어북 중 일부만 빠진 채 저장되었어요.**
- 아바타 이미지가 깨졌거나 CDN/차단 오류 응답이 오면 기본 아바타가 들어간 불완전 시트를 만들지 않도록 **의도적으로 임포트를 중단**합니다. 잠시 후 다시 시도해 주세요.
- 반면 로어북은 용량이 크거나 일부 응답·엔트리가 불완전·빈 상태일 때 **반쪽 파일을 만들지 않기 위해 해당 로어북만 건너뛰고**, 완결된 로어북들과 캐릭터 시트만 안전하게 저장합니다.

**Q. 토큰은 얼마나 자주 다시 넣어야 하나요?**
- `janitor_refresh_token` 이 저장되어 있다면 만료 전이나 `401` 응답 시 자동으로 갱신해 `token.json`을 업데이트합니다. 재니터 웹에서 직접 로그아웃만 하지 않으면 재등록하지 않아도 됩니다.
