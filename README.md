# Silly-CloudFix ☁️

> **실리태번(SillyTavern) 코어 수정 없이, JanitorAI 및 JannyAI의 공개 캐릭터 시트와 연결된 로어북을 완벽하게 가져오는 서버 플러그인**

---

## 🌟 개요 및 원리

실리태번의 기본 '구름 불러오기(Cloud Import)' 기능은 현재 JanitorAI의 API 구조 변경 및 Cloudflare 방화벽 차단으로 인해 정상 작동하지 않습니다.

**Silly-CloudFix**는 실리태번의 코어 소스코드를 단 한 줄도 건드리지 않는 **독립 서버 플러그인(Server Plugin)**입니다.
- **Git 충돌 제로**: 실리태번 공식 업데이트(`git pull`) 시 코드 충돌이 전혀 발생하지 않습니다.
- **인터셉터 구조**: 실리태번 내부 Express 라우터 앞단에서 클라우드 임포트 요청(`/api/content/importURL`, `/importUUID`)을 낚아채어 처리합니다.
- **정식 API & 자동 갱신**: 사용자의 JanitorAI 계정 인증(Supabase)을 기반으로 정식 API를 호출하며, **한 번 등록해 둔 리프레시 토큰을 이용해 백엔드가 스스로 만료된 토큰을 자동 갱신**합니다.

---

## ✅ 지원하는 기능 (되는 것)

1. **JanitorAI 공개 캐릭터 시트 완벽 임포트**:
   - 캐릭터 설명(`Description`), 성격(`Personality`), 첫 번째 메시지(`First Message`), 대체 첫 메시지 목록(`Alternate Greetings`), 시나리오(`Scenario`), 크리에이터 노트 등 모든 필드를 원본 그대로 보존합니다.
   - 검색이나 UI 표시를 망치는 유니코드 태그 이모지는 자동으로 정제되고 텍스트 및 `#` 태그만 깔끔하게 보존됩니다.
2. **연결된 공개 로어북 전체 일괄 다운로드**:
   - 캐릭터 시트에 연결된 모든 공개 로어북을 실리태번의 `worlds/` 폴더에 각각 독립된 파일로 안전하게 다운로드합니다.
   - 이미 동일한 이름의 로어북이 존재할 경우 기존 파일을 덮어쓰지 않고 `(2)`, `(3)`... 넘버링을 붙여 보존합니다.
   - 대표 로어북 1개는 캐릭터 기본 로어로 자동 연결됩니다. (추가 로어북은 실리태번 로어북 드롭다운에서 수동으로 연결 가능)
3. **JannyAI 링크 지원**:
   - 구름 모달에 `https://jannyai.com/characters/...` 링크를 붙여넣어도 캐릭터 UUID를 자동으로 인식하여 재니터 정식 데이터를 검색 및 다운로드합니다.
4. **다중 링크 일괄 다운로드 (원본 구름 기능 지원)**:
   - 클라우드 입력창에 여러 개의 캐릭터 링크를 엔터(줄바꿈)로 입력하면 순차적으로 일괄 다운로드됩니다.

---

## ❌ 지원하지 않는 기능 (안되는 것)

1. **비공개(Private) 캐릭터의 고급 정의(성격, 시나리오 등) 및 비공개 로어북**:
   - 제작자가 비공개(Private) 처리하여 아코디언이 가려진 캐릭터는 재니터 서버 API 자체에서 정의 데이터를 내려주지 않습니다.
   - 비공개 캐릭터 링크 입력 시, 재니터에서 대화 시작 시 열람 가능한 **첫 번째 메시지(`First Message`) 및 대체 첫 메시지(`Alternate Greetings`)까지만** 가져와집니다.
2. **재니터 원본에서 완전히 삭제된 캐릭터**:
   - JannyAI에 링크가 남아있더라도 재니터 원본 서버에서 삭제된 캐릭터는 가져올 수 없습니다. (`jannyai.com` 자체 서버는 엄격한 Cloudflare Turnstile 봇 방화벽이 걸려 있어 서버 스크래핑이 불가능합니다.)
   - *팁: JannyAI에만 존재하는 캐릭터는 웹 브라우저에서 직접 **`Download Card (.png)`** 버튼을 눌러 받은 뒤 정상 사용 가능합니다.*

## 📥 설치 및 설정 방법

### Step 1. `config.yaml` 에서 서버 플러그인 활성화
실리태번 루트 폴더에 있는 `config.yaml` 파일을 텍스트 편집기로 엽니다.
```yaml
# config.yaml
enableServerPlugins: true   # 기본값인 false를 true로 변경
```
> [!IMPORTANT]
> `enableServerPlugins: true`가 설정되어 있지 않으면 실리태번이 `plugins/` 폴더를 로드하지 않습니다.

---

### Step 2. 플러그인 폴더에 설치
> ⚠️ **주의**: 실리태번 웹 화면의 '확장 다운로드(Download Extension)' 메뉴는 클라이언트 확장(`extensions/`) 전용입니다. **Silly-CloudFix는 서버 플러그인이므로 반드시 `plugins/` 폴더에 설치해야 합니다.**

- **방법 A: Git Clone (권장)**
  실리태번 설치 경로의 `plugins` 디렉터리에서 터미널을 열고 실행합니다:
  ```bash
  git clone https://github.com/jjffdd1100-star/Silly-CloudFix.git
  ```
- **방법 B: 수동 압축 풀기 (ZIP)**
  1. 본 GitHub 저장소 우측 상단 `Code` -> `Download ZIP` 클릭
  2. 압축을 풀어 폴더명을 `Silly-CloudFix` 로 변경
  3. 실리태번의 `plugins` 폴더 안에 넣기
  - **올바른 폴더 구조**:
    ```text
    SillyTavern/
    ├── config.yaml
    └── plugins/
        └── Silly-CloudFix/
            ├── extractor.html     <-- 토큰 자동 추출 도구 (더블클릭 실행)
            ├── index.js
            ├── package.json
            ├── token.json         <-- 기본 포함된 빈 설정 파일
            └── README.md
    ```

---

> [!CAUTION]
> ### ⚠️ [필독] 반드시 실사용하지 않는 계정(서브 계정)의 API 키를 사용하세요!
> 재니터(JanitorAI) 측의 외부 API 접근 모니터링, 봇 탐지 정책 또는 세션 토큰 갱신 과정으로 인해 **기존 재니터 계정의 채팅 내역 및 보관 데이터가 전부 초기화(삭제)될 위험**이 있습니다.

### Step 3. 재니터 키(Key) 및 리프레시 토큰 따기 (💡 `extractor.html` 활용)

복잡한 수작업이나 LLM 질문 없이, **플러그인 폴더에 포함된 `extractor.html`을 더블클릭**하여 3초 만에 토큰을 추출할 수 있습니다!

1. PC 브라우저(크롬, 엣지 등)에서 [janitorai.com](https://janitorai.com) 에 **부계정(서브 계정)**으로 로그인합니다.
2. 키보드의 **`F12`** 키를 눌러 개발자 도구를 엽니다.
3. 상단 탭에서 **`Network` (네트워크)** 탭을 클릭합니다.
4. 재니터 화면에서 아무 캐릭터나 클릭하거나 새로고침(`F5`)을 누릅니다.
5. 네트워크 목록에 수많은 요청이 나타나면, 아무 요청(예: `characters`, `hampter`, `me` 등)이나 클릭합니다.
6. 우측 창의 **`Headers` -> `Request Headers` (요청 헤더)** 목록에서 **`Cookie:`** 뒷부분(또는 Request Headers 텍스트 전체)을 드래그해서 복사(`Ctrl + C`)합니다.
7. 플러그인 폴더에 들어있는 **`extractor.html`** 파일을 더블클릭하여 웹 브라우저에서 엽니다.
8. 입력창에 복사한 내용을 붙여넣고 **[🔑 토큰 추출하기]** 버튼을 클릭합니다.
9. 아래에 완성된 JSON 코드의 **[📋 token.json 내용 복사]** 버튼(또는 **[💾 token.json 파일 다운로드]**)을 누릅니다.

> [!NOTE]
> `extractor.html`은 100% 사용자의 PC 브라우저 로컬 안에서만 실행되며, 어떠한 토큰이나 개인정보도 외부 서버로 전송되지 않습니다.

---

### Step 4. `token.json` 파일에 토큰 등록
플러그인 폴더 안에 기본으로 포함되어 있는 **`token.json`** 파일을 열고, 위에서 복사한 내용을 그대로 덮어씌워 저장합니다.  
*(또는 `extractor.html`에서 다운로드받은 `token.json` 파일을 플러그인 폴더에 그대로 덮어쓰기 하셔도 됩니다!)*

- **파일 경로**: `SillyTavern/plugins/Silly-CloudFix/token.json`

```json
{
  "janitor_refresh_token": "여기에_추출한_리프레시_토큰_붙여넣기",
  "janitor_key": "여기에_추출한_긴_JWT_액세스_토큰_붙여넣기"
}
```

> [!TIP]
> - 파일을 새로 생성할 필요 없이, 이미 포함되어 있는 `token.json` 파일의 빈칸을 채워주시기만 하면 됩니다!
> - 실리태번 메인의 `secrets.json`을 건드리지 않으므로 기존 API 키들이 손상될 위험이 0%입니다.
> - `janitor_refresh_token`이 등록되어 있으면, 키가 만료되더라도 **플러그인이 백그라운드에서 Supabase 인증을 통해 스스로 새 키를 갱신하고 `token.json`에 자동 저장**하므로 이후 신경 쓰실 필요가 없습니다!
> - ⚠️ **주의**: 웹 브라우저에서 재니터 계정을 **직접 [로그아웃(Log out)]하시면 리프레시 토큰이 서버에서 즉시 만료(폐기)**됩니다. 토큰을 딴 이후에는 브라우저에서 로그아웃을 누르지 마시고 탭이나 창만 그냥 닫아두세요!

---

### Step 5. 실리태번 서버 재시작 (★ 필수)
일반 클라이언트 확장과 달리, **서버 플러그인은 실리태번의 백엔드(Node.js Express)가 처음 부팅될 때 로드**됩니다.
- 브라우저 창만 새로고침(`F5`)해서는 플러그인이 로드되지 않습니다.
- 실행 중인 실리태번 터미널(콘솔 창)을 닫고, **`Start.bat` 등으로 서버를 완전히 재구동**해 주세요!
- 부팅 시 콘솔 창에 `[Silly-CloudFix] Initializing plugin...` 로그가 출력되면 성공적으로 로드된 것입니다.

## 🎮 사용 방법

### 1. 캐릭터 가져오기
1. 실리태번 상단 바의 **구름 아이콘 (Cloud Import / 클라우드 불러오기)** 을 클릭합니다.
2. 가져오고 싶은 캐릭터의 URL을 입력하고 다운로드를 누릅니다:
   - **단일 링크**: `https://janitorai.com/characters/...` 또는 `https://jannyai.com/characters/...`
   - **일괄 링크**: 여러 링크를 엔터(줄바꿈)로 구분하여 한 번에 여러 개 입력 가능
3. 캐릭터 카드와 아바타, 로어북이 실리태번에 정상 저장됩니다.

### 2. 로어북 추출 및 동기화 (★ 중요)
1. 로어북이 포함된 캐릭터를 가져온 직후에는 화면 우측 상단에 **"카드에 로어북이 임베드되어 있습니다"** 토스트 알림이 뜹니다.
2. **[추가 설정들...]** 메뉴를 클릭합니다.
3. 메뉴 안에서 **[카드 로어북 가져오기]** 버튼을 클릭하면, 캐릭터 카드에 포함된 모든 로어북이 실리태번의 `worlds/` 폴더로 추출 및 다운로드됩니다!
4. 대표 로어북 1개는 캐릭터 기본 로어로 자동 연결되며, 추가 로어북이 있다면 로어북 서랍 드롭다운에서 원하는 대로 선택하여 연결할 수 있습니다.

> [!WARNING]
> **로어북 수정 시 주의사항**:
> **[카드 로어북 가져오기]** 기능은 카드에 임베드된 원본 로어북 데이터를 바탕으로 실리태번의 로어북을 **최신 상태로 동기화(초기화)**하는 기능입니다.
> 따라서 **기존에 실리태번에서 해당 로어북의 내용을 직접 수정해 둔 상태**에서 이 버튼을 다시 누르게 되면, **내가 수정한 내용이 원본 데이터로 덮어씌워져 초기화**되므로 주의하시기 바랍니다!

## ❓ 자주 묻는 질문 (FAQ)

**Q. 플러그인이 로드되지 않아요.**
- `config.yaml` 에서 `enableServerPlugins: true` 로 설정되어 있는지 확인하세요.
- 설치된 경로가 `data/default-user/extensions/`가 아니라 반드시 **`SillyTavern/plugins/Silly-CloudFix/`** 이어야 합니다.

**Q. 로어북이 여러 개인데 대표 로어북 1개만 연결되어 있어요.**
- 실리태번 규격상 캐릭터 카드 자체에는 기본 로어북 1개만 직접 매핑됩니다. Silly-CloudFix는 캐릭터에 연결된 나머지 2번, 3번 로어북도 빠짐없이 `worlds/` 폴더에 완벽하게 다운로드해 두므로, 로어북 서랍의 드롭다운에서 원하는 로어북을 바로 추가 연결하시면 됩니다.

**Q. 토큰이 만료되면 어떻게 되나요?**
- `janitor_refresh_token`이 설정되어 있다면 플러그인이 다운로드 요청 시 토큰 만료를 감지하고 자동으로 재발급받아 처리합니다. 재설정할 필요가 없습니다.
